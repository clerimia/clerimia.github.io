为什么这样分配

各自有表达，也有明确边界。

若叶睦：轻盈而有方向

画布近白，文字偏深灰绿；身份与行动分别命名，当前都使用苔绿。薄荷只用于局部的柔和反馈。

不要：整页铺绿，或让浅薄荷承载关键正文。

墨提斯：鲜活且有张力

绿色延续同一个人的身份（品牌、首页名字与提示符用户名）；双头像由人物提供身份线索，圆形图片只留细边线。酒红回应行动（主要链接与合适的交互状态）。每日一言回归中性或身份绿，主题开关只在操作时反馈。

不要：将酒红等同危险，因「表达」给非行动内容染红，或用深酒红直接绘制深底小字。文章图示保留服务内容的分类色，键盘焦点使用独立焦点色。

关系优先

同一组内使用较小间距，不同内容组使用更大间距；长文段落按阅读节奏安排。

建议起点：组件内部 24px；手机左右 20px；重要区块间 72px，手机 40px。遇到长文或复杂布局时根据真实内容调整。

不要：用固定值把不同信息关系压成同一种节奏。

04 页面框架与断点

从手机的单列阅读与触屏操作出发，随空间增加再安排内容；宽屏先保护阅读宽度，再决定目录能否并列。

≤ 680px · 紧凑 两侧 20px

单列；简介与头像上下排列。完整品牌与工具保持一行，栏目与搜索进入菜单，目录通过入口打开。

> 680 且 < 1000px · 过渡 两侧 24px

单列阅读；目录收进入口，列表辅助信息移到主内容之后。页头 ≤760px 使用菜单，更宽时显示整行栏目。

≥ 1000px · 宽屏 两侧 32px

内容容器达到 936px 才并列；没有目录就不预留空栏。

返回与页头：About、Links、列表和内容页的返回入口、页头与页框共用左基线，入口到底下的正文保持 24px。阅读列限宽时靠左；标题前如有文章日期、标签或封面，保留内容自己的层级。已通过 BaseLayout / ContentLayout 的 back 与 .site-page-main 接入，例外应记录理由与验证方式。

手机先行：两侧各 20px 时，320 / 390 / 430px 的可用宽度分别约为 280 / 350 / 390px（未扣除安全区与滚动条）。正文以 16px / 1.8 为起点，目录收进可关闭的入口；触控目标优先达到 44 × 44 CSS px。

为什么是 680px？保留为页框边距和首页布局规则；页头独立采用 760px 内容断点，窄屏从顶部就折叠栏目与搜索，滚动不改变导航结构。

悬浮页头 · 2026-10-28 修订：用户已确认 Joye Blog 四种状态的参考方向；本地实现，浏览器与真实设备验证分别记录。保持完整绿色 c. clerimia 字标、终端、主题和菜单的顺序；标语在 1100px 及以上显示，较窄时为导航留出空间。桌面 / 移动默认高 72 / 64px，滚动超过 32px 时收拢为 60 / 56px，回到 8px 内恢复，流内占位固定。悬浮栏距安全区至少 12px，宽屏左右收拢 clamp(12px, 4vw, 48px)、内边距 12px；移动保留页框外边距、栏内 8px。字标字号、布局模型和工具保持稳定，正文不跳动。

工具与菜单：工具命中区域 44×44px，通过内部 4px 留白形成 36px 的细边框。桌面搜索、终端与主题开关同属一个右侧工具组，容器间距 4px，按钮边框间可见约 12px；移动端搜索留在导航菜单，顶部保留终端、主题和菜单。悬浮栏沿用画布、边线及 16px 圆角，以轻阴影标明浮于正文上方的层次。移动菜单在页头下方 8px 纵向、右对齐展开，栏目与搜索行至少 48px，当前栏目只用字重并保留 aria-current；面板可内部滚动。关闭时立即 inert 并播放退出动画，支持键盘、Escape、外部点击、离开焦点关闭及焦点恢复；跨滚动阈值和视口高度改变不主动关菜单。

目录入口：单列布局在视口右下角安全区放置圆形目录按钮，与返回顶部按钮并排；目录始终最靠右，返回顶部出现后在左侧。两者触控区域至少 44×44px、间距 8px，离视口边缘至少 20px；宽屏目录并列时隐藏浮动入口。该常驻浮动入口是用户明确选择的移动端模式，会覆盖按钮下方少量页面区域，以小型图标和安全区留白限制遮挡。抽屉进出均使用 220ms、至多 8px 位移；关闭后焦点回到打开抽屉的按钮。正文标题、评论和正文入口使用 scroll-margin-top: 96px。实现位于 ContentLayout.astro；760px 仍需真实设备、放大字体和缩放验证。

为什么是 1000px？估算：宽屏阅读列目标 680 + 列间 32 + 目录 224 + 两侧各 32 = 1000。实际还要求内容容器至少 936px；滚动条、安全区等占用空间时，放不下就保持单列。这里的 680 是阅读列目标，并非手机正文最小宽度。

如何验证：检查 320–430px、断点两侧、横屏与 200% 缩放。长标题应换行，代码和表格只在自身区域滚动；导航若横向滚动，要提示还有内容并支持键盘操作。浏览器模拟不能代替真实设备验证。
