# clerimia 前端设计系统 · 提案

本文件是设计系统的**文字规范**：定义色彩、排版、尺度、组件和验证方法，供设计与实现查阅。[可视化规范](design-language.html) 展示同一套规则及样例，两者应保持一致。[Design.md](../Design.md) 记录灵感和大方向，[AGENTS.md](../AGENTS.md) 是仓库入口与工作约定。

**状态：面向未来的设计提案。** 所有值是设计初稿，不代表现有页面或 CSS 已经实现，也不代表完成实际页面验收。实施前结合真实内容、两套主题及不同设备验证；规则调整时同步更新本文与 HTML。若两份规范不一致，先核对设计意图和最新决定再统一，不以现有代码自动覆盖提案。设计意图来自 [博客设计思路](https://app.notion.com/p/40540f8bc1e6804ab903fa51c4225aae)、[设计取舍](https://app.notion.com/p/40540f8bc1e681a39bfdd40e8c0beaf5) 和用户补充的墨提斯主题气质。

## 理念与主题

**安静，但有自己的声音；整体安静，局部鲜活。** 文章、项目和持续变化的思考是主体。绿色和双头像是个人识别，互动细节表达情绪；不以大量装饰证明个性。

- **若叶睦（日间）**：安静、轻盈、柔和。近白画布、深灰绿文字、低饱和苔绿和薄荷局部表面。
- **墨提斯（夜间）**：开放、活力、戏剧性。炭灰画布、鲜活绿色与酒红共同构成情绪；绿色提示行动，酒红用于精选、主题细节和个人表达。

两套主题各自拥有完整色板，共享语义职责、内容结构、布局、排版和组件交互。酒红不是错误色；主题差异不应改变阅读顺序和操作习惯。

## 01 色彩系统

| 提议语义 | 若叶睦 | 墨提斯 | 作用 / 边界 |
| --- | --- | --- | --- |
| `--color-canvas` | `#f9fcf9` | `#191d1c` | 页面画布；不以大面积渐变干扰阅读 |
| `--color-surface` | `#ffffff` | `#262d29` | 确需独立的面板、浮层；普通列表优先平面 |
| `--color-text` | `#263b2e` | `#eaf1eb` | 标题、正文 |
| `--color-text-muted` | `#536a5b` | `#aebeb2` | 摘要、元信息；重要信息仍须清楚 |
| `--color-action` | `#3f7050` | `#a9d8b4` | 链接、主要行动、当前状态 |
| `--color-action-ink` | `#ffffff` | `#171e19` | 实心主要操作上的文字 |
| `--color-selection` | `#e8f2ea` | `#334638` | 选中与轻量反馈；实际前景配对待测 |
| `--color-expression` | 不设默认 | `#80364b` | 墨提斯表达与局部强调，不表示错误 |
| `--color-expression-surface` / `--color-expression-ink` | 不设默认 | `#38232a` / `#efb9c7` | 可阅读的酒红局部表面与文字 |
| `--color-border` | `#d0ded2` | `#43544a` | 装饰性分隔，不作为必要控件边界 |
| `--color-focus` | `#315a40` | `#a9d8b4` | 键盘焦点环；按实际表面测量 |

纯色计算：正文对画布分别为 11.63:1 / 14.82:1，辅助文字为 5.68:1 / 8.76:1，操作色为 5.57:1 / 10.67:1；操作文字对操作底为 5.76:1 / 10.65:1；浅酒红文字对酒红表面为 8.62:1。以上不覆盖渐变、透明度、hover 或图片。普通文本以 4.5:1、必要控件边界与状态以 3:1 为目标；需要更强的控件边界时针对实际表面另行设计。成功、警告、错误在真实需求出现时建立可读配对，并辅以文字或图标。

## 02 字体与字号

字体：Satoshi 配 Microsoft YaHei、system-ui 回退；代码与终端用 ui-monospace、Consolas、monospace。中文标题从正常字距开始，英文品牌字标可独立微调。正文用 400，标题及重点以 600–700 为起点；不要通过降低正文对比度表达安静。

| 提议角色 / token | 桌面字号 / 行高 | 手机字号 / 行高 | 主要用途 |
| --- | --- | --- | --- |
| Display `--font-display` | 48 / 1.2 | 34 / 1.2 | 首页主标题 |
| Page title `--font-page-title` | 36 / 1.25 | 28 / 1.3 | 文章和页面标题 |
| Section `--font-section` | 24 / 1.35 | 22 / 1.35 | 区块标题 |
| Item title `--font-item-title` | 18 / 1.45 | 18 / 1.45 | 文章条目标题 |
| Lead `--font-lead` | 18 / 1.75 | 17 / 1.75 | 简介、引言 |
| Reading `--font-reading` | 16 / 1.8 | 16 / 1.8 | 长文正文 |
| UI `--font-ui` | 14 / 1.6 | 14 / 1.6 | 导航、按钮、短摘要 |
| Meta `--font-meta` | 12 / 1.5 | 12 / 1.5 | 日期与辅助信息 |

手机档位以 680px 以下为初稿。文章列先比较 680–760px 与真实中英文行长，响应式收缩；12px 仅用于少量非关键元信息。按内容检查字号、换行、字重与间距，不因为字号表存在就机械套用。

## 03 间距、圆角、尺寸、图标

- **间距**：`--space-1/2/3/4/5/6/8/12/18` 分别为 4/8/12/16/20/24/32/48/72px。同组间距小于组间距；手机页面两侧 20px、大区块间 40px 可作为起点。
- **圆角**：代码 6px、控件 10px、面板 16px、对话框 24px、胶囊 999px；文章行优先无外框。圆角依据职责，而非所有内容都成卡片。
- **控件高度**：32px 密集控件、44px 默认、52px 突出入口；交互目标优先至少 44×44 CSS px。小型视觉控件应扩大命中区域并避免互相重叠。
- **图标**：16px 行内、18px 默认、20px 突出控件；线性风格，视觉线宽约 1.75–2px，优先复用现有图标集。图标按钮有可访问名称与可见焦点。
- **表面和动效**：常规内容平面；对话框等浮层可用阴影。状态反馈约 160ms、弹层约 200ms、主题切换约 220ms 为起点；正文不持续运动，尊重减少动态效果。
- **布局**：站点容器最大 1080px 为初稿；正文列独立约束。手机两侧 20px 起，日夜共用布局。实际断点由内容决定。

## 组件与交互

导航当前项可辨且使用 `aria-current`；颜色不能是唯一状态线索。主要行动每个区域保持清楚，次要行动降低权重；链接和按钮分别使用原生语义。文章列表优先标题、日期和摘要组成的行，项目确有独立内容时可使用卡片。标签是辅助信息，状态需有文字。主题切换保存用户选择并同步名称和状态；对话框及移动目录检查焦点进入、退出和恢复、Escape、键盘顺序与触屏。

## 从提案到实现

当前项目的色值、字号和组件不代表上述方案已实施。下一步先以首页、文章列表和文章详情制作局部样例，日夜各做宽屏与 390px 比较；测实际背景和状态对比度、标题换行、阅读宽度、焦点、触控目标与减少动态效果。再将通过验证的规则逐步映射到 `src/assets/styles/app.css`、组件和主题兼容变量；每一阶段保留截图与取舍，不批量替换未验证值。UI 改动运行 `npm run check` 和 `npm run build`。
